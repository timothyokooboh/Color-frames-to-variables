# Issue tracker: GitHub

Issues and specs live in timothyokooboh/Color-frames-to-variables.
Use the gh CLI from this repository.

- Publish a spec or ticket: create a GitHub issue.
- Fetch a ticket: read its body, labels, and comments.
- For multiline issue bodies and comments, write the text to a
  temporary file and pass --body-file.
- Link related issues and use native sub-issues and dependencies
  when available. Otherwise, record relationships in issue bodies.

PRs as a request surface: no.
